# SURVIVORS WEAR — Editorial E-commerce

A clean React + TypeScript + Vite fashion storefront inspired by modern editorial fashion-site principles, with an original SURVIVORS WEAR identity.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Included

- TSX / React / Vite
- No router dependency and no icon dependency
- Home, collection, product, about, and account views
- Responsive 4/3/2-column product grids
- Animated full-screen navigation
- Full-screen search
- Slide-out shopping bag
- Quick view
- Product sizing and add-to-bag
- Persistent cart with localStorage
- Editorial scroll reveals
- Hero animation and parallax-style image motion
- Custom cursor on desktop
- Scroll progress indicator
- Mobile navigation and mobile-first layouts
- Reduced-motion support
